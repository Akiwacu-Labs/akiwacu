- Propriétaire : Gloria Muhimpundu (`@muhimpundugloria`)
- Périmètre : création et suivi des demandes de prêt.
- Règles couvertes : R2, R4, R6 et R7 avec les domaines partenaires.

- Les prêts actifs ne sont pas déduits du calcul R6.
