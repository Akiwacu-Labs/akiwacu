# Domaine recu

Propriétaire : Juste Daxa Ayikunde.

`RecuService` est le contrat partagé consommé par les domaines cotisation, prêt et remboursement.
Cette première version expose l'interface afin de débloquer la compilation des domaines dépendants.
La génération OpenPDF, la numérotation et le téléchargement sont livrés dans une PR dédiée après validation du contrat de persistance.
